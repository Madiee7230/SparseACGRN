# Datasets
# Madrid Traffic Dataset

Gómez, Iván; Ilarri, Sergio (2026), Enriched Traffic Datasets for Madrid, Mendeley Data, V4. DOI: 10.17632/697ht4f65b.4

Source: https://data.mendeley.com/datasets/697ht4f65b/4

License: CC BY 4.0

We use two versions of the Madrid Traffic Dataset:

Madrid subset (subset_300)

Contains traffic data for 300 sensors, covering June 2022 to October 2023. This is the dataset used for our initial traffic forecasting experiments.

Madrid full (full_554)

The source dataset describes 554 sensors and covers June 2022 to November 2024. The HDF5 files currently used in this project contain 553 sensors, with matching sensor-location records.

# LargeST Dataset

Liu, Xu et al. (2023), LargeST: A Benchmark Dataset for Large-Scale Traffic Forecasting, Advances in Neural Information Processing Systems (NeurIPS).

Source: https://www.kaggle.com/datasets/liuxu77/largest

License: CC BY-NC 4.0

We use two LargeST datasets:

California (ca_8600)

Contains 8,600 traffic sensors across California, with traffic measurements at five-minute intervals from 2017 to 2021. The dataset includes sensor metadata and a road-network adjacency matrix.

Greater Bay Area (gba_2352)

Contains 2,352 sensors from California District 4. The GBA data is extracted from the California dataset while preserving the original sensor order, timestamps, and road-network connections.
